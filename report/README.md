# Report build

## Files

- `main.tex` — paper source (single file, no custom style files)
- `references.bib` — BibTeX entries
- `figures/per_group_accuracy.{pdf,png}` — generated by `scripts/make_paper_figures.py`
- `figures/aggregate_metrics.{pdf,png}` — same script (not currently cited in main.tex; available if needed)

## Building on Overleaf (recommended, no local install)

1. New project -> Upload project -> upload `main.tex`, `references.bib`, and the `figures/` folder.
2. Compiler: `pdfLaTeX`, with BibTeX as the bibliography backend.
3. Click `Recompile`. Two passes (pdflatex -> bibtex -> pdflatex -> pdflatex) are usually needed to resolve all citations.

## Building locally (MiKTeX / TeX Live)

```
cd report
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Or, with `latexmk` installed:

```
cd report
latexmk -pdf main.tex
```

## Regenerating figures

If `sweep_summary.json` is updated (e.g. after a new sweep run), regenerate the figures:

```
python scripts/make_paper_figures.py
```

This reads `results/sweep_summary.json` and overwrites both `.pdf` and `.png` figure files.
